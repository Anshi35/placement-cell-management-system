# 🎓 Placement Cell Management System

A web-based Placement Cell Management System that simplifies and automates the campus placement process. It provides an efficient platform for students, placement officers, and recruiters to manage placement-related activities.

---

## 📌 Features

### 👨‍🎓 Student Module
- Student Registration and Login
- Update Personal and Academic Details
- View Eligible Companies
- Apply for Job Drives
- Track Application Status

### 👨‍💼 Placement Officer Module
- Secure Login
- Manage Student Records
- Add, Update, and Delete Company Details
- Schedule Placement Drives
- View Student Applications
- Generate Placement Reports

### 🏢 Company Module
- Company Registration
- Post Job Opportunities
- View Eligible Candidates
- Shortlist Students

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Placement-Cell-Management-System.git
```

2. Navigate to the project folder

```bash
cd Placement-Cell-Management-System
```

3. Install dependencies

```bash
npm install
```

4. Configure the MySQL database.

5. Start the server

```bash
npm start
```

6. Open your browser and visit

```
http://localhost:3000
```
